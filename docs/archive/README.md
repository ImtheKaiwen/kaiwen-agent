# Archive

Historical planning documents written in Turkish before and during the first
implementation phases. They are kept unmodified for provenance and are not
authoritative. The checked-out code, `docs/architecture.md`, the accepted records in
`docs/decisions/`, and `docs/roadmap.md` take precedence wherever they differ.

| File | Content |
| --- | --- |
| `kaiwen_reusable_agent_framework_architecture.md` | Original reusable agent framework architecture proposal |
| `kaiwen_reusable_agent_implementation_plan.md` | Original phased implementation and integration plan |
| `realtimelive_api_entegrasyonu.md` | Original Realtime / Live API integration proposal |

The documents refer to the platform repository as `kaiwen-agent-platform`; the
current repository name is `kaiwen-agent`. They refer to each other by bare file
name, which remains valid because all three live in this directory.
